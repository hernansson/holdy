IBKR automático

Holdy trae solo tus operaciones, dividendos y efectivo de Interactive Brokers una vez por día. Necesita el token del Flex Web Service (IBKR → Performance & Reports → Flex Queries → Flex Web Service Configuration) y el número de tu Flex Query (en formato CSV, con Trades, Cash Transactions y Cash Report). El token solo sirve para leer reportes: no permite operar ni mover plata.
